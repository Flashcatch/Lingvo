# Немецкий: словарь «пузыря» Duolingo (разделы 1–2)

| Файл | Что это |
|---|---|
| `vocab_source.txt` | Исходный список слов: его и нужно править (удалить лишнее, добавить недостающее) |
| `build_dictionary.py` | Сборка: спрягает глаголы, склоняет прилагательные, считает словоформы |
| `dictionary.json` | Готовый машиночитаемый словарь, основа для будущего тренажёра |
| `СЛОВАРЬ.md` | Тот же словарь в виде таблиц по разделам и темам |

Пересобрать после правок:

```bash
python3 build_dictionary.py
```
